# 📈 AI-Powered Sales Forecasting Dashboard

## 🚀 Overview

This tool analyzes historical sales data from the "Superstore" dataset to predict future performance. It aggregates daily sales, handles seasonality, and generates a 90-day forecast.

**Key Features:**
* **Automated Data Processing:** Handles date parsing and aggregation automatically.
* **Machine Learning:** Uses the **Prophet** library for accurate time-series forecasting.
* **Visual Output:** Generates Python plots for immediate analysis.
* **Power BI Integration:** Exports predictions to `forecast_for_dashboard.csv` for external dashboarding.

## 🛠️ Tech Stack

* **Python 3.x**
* **Pandas** (Data Manipulation)
* **Prophet** (Time Series Forecasting)
* **Matplotlib** (Visualization)
